# Indonesia E-Commerce Sales Analysis

## 📌 Project Overview
This project presents an analysis of e-commerce transaction data in Indonesia, focusing primarily on order performance mapping (*Orders Summary Overview*). The analysis aims to identify monthly order volume growth trends throughout the year, detect market concentration based on geographic region distribution, and analyze product category dominance by transaction volume. All visualizations were designed using **Microsoft Power BI** to provide clear operational insights in support of marketing strategies and logistics distribution.

---

## 🛠️ Tools & Technologies Used
- **Business Intelligence & Visualization:** Microsoft Power BI
- **Data Source:** External E-Commerce Sales Dataset

---

## 📊 Dashboard & Features
The Power BI dashboard in this project is designed to showcase:
- **Orders Count by Month (Line Chart):** Displays the monthly order volume growth trend from January to November.
- **Orders Count by Region (Donut Chart):** Identifies the geographic distribution of customer orders across various regions in Indonesia.
- **Count of Orders by Product Categories (Bar Chart):** Analyzes transaction volume performance categorized by product types.
